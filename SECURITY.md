# Security Policy

## Supported Versions

Security fixes are handled for the latest public release.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Please do not publish private access files, cookies, tokens, passwords, logs with personal paths, or account data in public issues.

For download errors, use the application's sanitized report button or open a GitHub issue with:

- app version;
- Windows version;
- service name;
- short description of the problem;
- sanitized error text.

The project never needs your account password.
